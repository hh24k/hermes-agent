What is Hermes?

A self-improving AI agent

Combines tool-calling, persistent learning, and multi-platform messaging into a single unified system — extensible, portable, and privacy-respecting.

🔄 Self-Improving Loop

Creates and refines skills autonomously from experience

🤖 Model-Agnostic

200+ models — Anthropic, OpenAI, Google, OpenRouter, Ollama, LM Studio

📡 25+ Platforms

Telegram, Discord, Slack, WhatsApp, Matrix, Signal, Email and more

🧠 Persistent Memory

FTS5 full-text search over all sessions with LLM summarization

🔧 Skills Hub

Open standard (agentskills.io) — share and discover skills

☁️ Serverless-Ready

Daytona & Modal with hibernation during idle periods

Usage

Getting Started

Install (Linux / macOS / WSL2)
$ curl -fsSL .../install.sh | bash
Then start
$ hermes
Config: ~/.hermes/config.yaml — 450+ documented options
hermesStart interactive TUI session
hermes chat -q "…"Non-interactive single query
hermes setupInteractive configuration wizard
hermes modelSwitch between 200+ models
hermes gatewayStart messaging gateway (Telegram, Discord…)
hermes skillsBrowse and install from Skills Hub
hermes cronManage scheduled automation tasks
hermes doctorDiagnose configuration issues

Deploy

Flexible Deployment

💻 Laptop CLI $0 Direct execution, daily AI assistant $ hermes
🖥️ VPS + systemd $5–20 / mo Always-on bot, any messaging platform $ hermes gateway start
🐳 Docker Variable Isolated, portable, reproducible $ docker run hermes
🌙 Daytona ~$1–5 / mo idle Serverless with hibernation, persistent state daytona create
⚡ Modal $0–10 / mo Scale-to-zero, pay only when running modal deploy
☸️ Kubernetes Enterprise Helm charts for production scale helm install hermes ./helm
