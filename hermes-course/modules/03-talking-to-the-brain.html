How the AI Knows What Tools Exist

Before each conversation, the AIAgent compiles a list of available tools and sends it to the LLM as part of the prompt. Each tool is described by a schema — a structured spec the model reads to know when and how to call that tool.

Here is the actual tool list from toolsets.py — the core tools every Hermes session loads:

CODE 

# From toolsets.py — the core tool list
_HERMES_CORE_TOOLS = [
    # Web
    "web_search", "web_extract",
    # Terminal + process management
    "terminal", "process",
    # File manipulation
    "read_file", "write_file", "patch", "search_files",
    # Skills
    "skills_list", "skill_view", "skill_manage",
    # Planning and memory
    "todo", "memory",
]
PLAIN ENGLISH

A list of tool names that are loaded for every session.

web_search: search Google. web_extract: read a webpage.

terminal: run shell commands. process: manage background processes.

Four file tools: read, write, apply a diff (patch), and search inside files.

Three skills tools: list available skills, view one, create/edit/delete them.

Two meta tools: todo (task tracking) and memory (write to long-term memory).

Each name in this list maps to a Python function in tools/. That function is what actually runs when the LLM asks for it. The schema (the description + parameter spec) is defined right next to the function code.

Running Tools in Parallel

When the LLM asks for multiple tools at once — say, "search the web AND read this file" — Hermes can run them in parallel instead of waiting for each one to finish. But not all tools are safe to run simultaneously.

1
Read-only tools are always parallel-safe

web_search, read_file, vision_analyze, session_search — these only read data. Running them simultaneously is safe because they do not change anything.

2
File-writing tools are parallel-safe for different paths

write_file and patch can run in parallel if they target different files. Writing to the same file at the same time would corrupt it.

3
Interactive tools are never parallel

The "clarify" tool asks you a question. Running two of these at once would produce two prompts simultaneously — impossible to answer. It always runs alone.

4
Up to 8 workers run at once

Hermes uses a thread pool of up to 8 parallel workers. If the LLM requests 10 tools, the first 8 start immediately, and the remaining 2 queue up.

⚡
Why This Matters in Practice

If you ask Hermes to "research 5 companies," it can open 5 web searches at the same time instead of 5 in a row. A task that would take 30 seconds sequentially can finish in 8 seconds. Knowing this helps you write prompts that take advantage of parallelism.

The AIAgent and LLM in Conversation

The AIAgent and LLM exchange messages in a structured format. Watch how a multi-tool request gets negotiated:

AI
AIAgent

[system] You are Hermes. Available tools: terminal, web_search, read_file, write_file... [user] Research the top 3 Python web frameworks and write a comparison to frameworks.md

LLM
LLM

I will call web_search("Python web frameworks comparison 2024"), web_search("FastAPI vs Django vs Flask"), and web_search("Python framework benchmarks") all at once.

AI
AIAgent

All 3 are read-only — running in parallel. Dispatching to thread pool... [800ms later] All done. Returning 3 sets of search results.

LLM
LLM

I have enough information. Calling write_file("frameworks.md", content=...) with the full comparison article.

AI
AIAgent

write_file executed. File created at frameworks.md. Feeding result back to LLM for final response.

LLM
LLM

Done! I researched and compared Django, FastAPI, and Flask. The comparison is saved to frameworks.md. Here are the key findings...
